# ASCII Art

## Description
ASCII Art is a command-line application written in Go that converts regular text into ASCII art using different banner styles.

The project supports three banner styles:
- Standard
- Shadow
- Thinkertoy

## Features
- Convert normal text into ASCII art.
- Support multiple banner styles.
- Handle spaces and special characters.
- Display output directly in the terminal.
- Read text input from command-line arguments.

## Technologies Used
- Go (Golang)
- Standard Go libraries
- ASCII banner text files

## Project Structure

```text
ascii-art/
├── main.go
├── go.mod
├── README.md
└── banners/
    ├── standard.txt
    ├── shadow.txt
    └── thinkertoy.txt
```

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd ascii-art
```

## Usage

Run the program using:

```bash
go run .
```

Example:

```bash
go run . "Hello"
```

## Banner Styles

**Standard**

```text
 _   _      _ _       
| | | | ___| | | ___  
| |_| |/ _ \ | |/ _ \ 
|  _  |  __/ | | (_) |
|_| |_|\___|_|_|\___/ 
```

**Shadow and Thinkertoy**

The program also supports Shadow and Thinkertoy banner styles.

## Requirements
- Go 1.18 or later.
